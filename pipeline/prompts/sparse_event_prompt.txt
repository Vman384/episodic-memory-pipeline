You are analyzing dashcam frames sampled in chronological order from one section
of a longer drive through forest, rural, tunnel, and sometimes snowy-road
environments.

Identify sparse, noteworthy observations that could help someone remember what
was distinctive about this part of the drive. Include both events or changes
and static details that provide useful context; an observation does not have to
be rare as an object category or involve motion.

Judge each detail by its specific visible content, condition, placement, or
relationship to the surrounding scene. For example, a common kind of object can
be worth recording when its particular message, symbol, marking, or state makes
it informative or memorable. Unusual localized objects, obstructions, hazards,
damage, or other clear changes to the scene may also be noteworthy. These are
broad examples, not a checklist.

Do not report routine driving, ordinary traffic, generic buildings, standard
roadside infrastructure, or unremarkable scenery just because they are visible.
Do not treat every common object or sign as noteworthy. Include it when its
specific visible content or condition gives useful context beyond ordinary
background scenery.

Respond with ONLY a valid JSON object. If no detail is sufficiently noteworthy,
return an empty `interesting_events` list.

{
  "interesting_events": [
    {
      "section_name": "Name of the section this event frame is from",
      "frame": "Exact frame filename that best supports the observation.",
      "event_description": "Describe the specific visible detail and its context.",
      "why_interesting": "What makes this particular detail distinctive or useful for remembering this part of the drive."
    }
  ]
}

Rules:
- The user message includes an ordered frame filename manifest. The first image
  corresponds to the first manifest entry, the second image to the second
  entry, and so on.
- Use the exact filename from the manifest for `frame`. Never invent filenames
  such as `image1.jpg` or `frame_0001.jpg`.
- Choose a frame that clearly supports the description. For text or fine detail,
  prefer a frame where it is legible; quote only words that are actually
  readable, and do not guess at obscured text.
- Describe only what is visually supported. Do not infer an object's meaning,
  cause, or significance when the frames do not establish it.
- Keep observations in chronological order and avoid repeating the same
  observation across multiple sampled frames in this section.
- Return an empty array when no detail meets the noteworthy threshold.
