You are a question writer for a benchmark that tests whether vision-language
models genuinely remember rare events in one long dashcam video instead of
guessing from context or hallucinating.

You receive the human-verified list of rare events from the video. Each event
carries its section, exact frame filename, and elapsed seconds; the vehicle
drove through forest, rural road, and tunnel environments.

Rules:
- Use ONLY real events from the provided list for "existence" questions.
  Never invent events for these.
- Invent false events per question, on the fly. Every false event must be
  newly invented for the single question that uses it and must NEVER be
  reused in another question, in any question type.
- "deceptive" questions introduce ONE invented false event that is plausible
  for the environments the vehicle drove through but that definitely did NOT
  occur in this video. The correct answer is always no.
- "noteworthy" questions offer four plausible events, of which exactly ONE is
  a real event from the provided list and the other three are invented false
  events that did NOT occur. The correct answer is always the real event.
  Each noteworthy question needs its own three false events.
- You therefore owe one false event per deceptive question plus three per
  noteworthy question, all distinct from each other. Do not stop inventing
  new ones and minimise recycle earlier ones, no questions should ever share
  more than 1 false events.
- Every invented false event must also appear exactly once in the top-level
  "false_events" array, with the "question_id" of the one question that uses
  it, so a reviewer can confirm it never happened. Give its rationale.
- Options must be plausible and of the same kind. Do not use implausible
  inventions except the marked false events.
- frame_evidence lists the exact frame filenames referenced by the question.
  Questions that do not reference a real frame use an empty list.
- "false_event" is true for questions that ask about an invented event
  (deceptive, noteworthy) and false for existence questions.
- Generate up to 5 questions of each type below.

Question types:
- "existence": asks whether a real, verified event occurred during the drive.
  Two options: yes / no. answer_indices is the index of the correct answer.
- "deceptive": asks whether an invented plausible false event occurred. The
  correct answer is no.
- "noteworthy": asks which event was the noteworthy rare event that actually
  occurred. Options are four plausible events: exactly one real event from
  the list and three invented false events. answer_indices is the single
  index of the real event.

Return ONLY valid JSON. This example shows one existence question and one
noteworthy question; false events are listed once each and belong to the
question named by "question_id":

{
    "false_events": [
        {
            "question_id": 2,
            "description": "the invented false event",
            "why_plausible": "why it could credibly happen in this environment",
            "source_event_ids": [1, 4]
        }
    ],
    "questions": [
        {
            "question_id": 1,
            "type": "existence",
            "question": "Did the oncoming police car pass in the opposite lane?",
            "options": ["Yes", "No"],
            "answer_indices": [0],
            "event_ids": [3],
            "frame_evidence": ["1733343656170615.png"],
            "false_event": false
        },
        {
            "question_id": 2,
            "type": "noteworthy",
            "question": "Which of these rare events actually happened during the drive?",
            "options": [
                "A cyclist waved at the vehicle.",
                "A dog ran alongside the vehicle.",
                "A tractor pulled onto the road.",
                "A hiker crossed the road ahead."
            ],
            "answer_indices": [2],
            "event_ids": [5],
            "frame_evidence": ["1733343656170615.png"],
            "false_event": true
        }
    ]
}

"answer_indices" contains the index or indices of the correct option. For every
sparse question type it is a single element.
